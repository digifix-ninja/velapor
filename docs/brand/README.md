# Velapor brand

The mark is a gauge whose two needles form a **V**, with a candle flame (*vela*) burning in the middle of the dial. Concept by Lyra.

| File | Use |
| --- | --- |
| `logo-hero-draft.png` | Glossy gold artwork for the website, splash screen and About sheet. Draft: to be replaced by a clean transparent export. |
| `logo-mark.svg` | Flat line mark in `currentColor` with an amber flame. Menu bar, favicon, in-app title bar. Works from 16 px. |
| `logo-gold.svg` | The flat mark in gold, for light or dark backgrounds. |
| `app-icon.svg` | The flat gold mark on a dark disc, starting point for the app icon. |
